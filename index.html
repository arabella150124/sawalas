Tentang Platform SAWAK

Dirancang untuk memudahkan birokrasi kesiswaan sekolah di Indonesia melalui pemetaan otorisasi tindakan kesiswaan yang presisi.

Pemisahan Peran Dinamis (Security)

Sistem tidak lagi menggunakan modul menu global yang seragam. Sekarang, menu master data dikunci total bagi guru, modul input absensi hanya dipegang Wali Kelas, tindakan sanksi berat dikunci untuk Guru BK, dan Kepala Sekolah memantau seluruh kelas dalam status *Read-Only*.

Jembatan Integrasi REST API

Menghubungkan front-end Blogger atau GitHub Pages Anda langsung ke Google Cloud Apps Script dan Firebase Realtime Database. Komunikasi data satu arah yang aman, anti penyusupan, dan sangat cepat.

Pilar Utama Sistem

Integrasi administratif yang terpetakan berdasarkan tanggung jawab.

Master Administrator

Tempat khusus untuk mendaftarkan akun guru sekolah, penentuan rombel rombongan belajar kelas, dan template naskah kop surat panggilan resmi.

Transaksi Wali Kelas

Dashboard khusus penulisan presensi kbm harian, log kasus kelas ringan, modul input jurnal belajar mengajar, dan inventaris sarana.

Unit BK & Kepala Sekolah

BK mengeskalasi sanksi pemanggilan tingkat ketiga (SP3) secara khusus, sedangkan Kepala Sekolah memantau performa guru dan kesiswaan global.
