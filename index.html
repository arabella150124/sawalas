Visi, Misi & Sinergitas

Menghubungkan birokrasi kesiswaan demi menumbuhkan karakter disiplin dan tanggung jawab siswa secara terukur.

Sinergi & Koordinasi

Otomatisasi pengiriman draf panggilan wali murid dari Wali Kelas ke unit Bimbingan Konseling (BK) mempercepat rantai penanganan indisipliner tanpa hambatan kertas berkas fisik.

Serverless & Real-time

Berjalan murni serverless berkat perpaduan tangguh Google Apps Script Web App dan REST API Firebase Realtime Database. Cepat, aman, dan tanpa biaya sewa server bulanan.

Pilar Fungsionalitas SAWAK

Satu ekosistem lengkap untuk melayani seluruh administrasi dan operasional harian ruang kelas.

Absensi Cerdas

Input harian cepat dan otomatis dikalkulasi ke dalam sistem deteksi ketidakhadiran berjenjang.

EWS Berjenjang

Otomatisasi pengkategorian status siswa (SP1, SP2, SP3) berdasarkan total hari ketidakhadiran (Alpa).

Cetak Surat Instan

Mencetak draf surat panggilan orang tua dan surat pernyataan komitmen siswa secara rapi menggunakan layout cetak.

Jurnal & P5

Inventaris Kelas

Manajemen sarana fisik, kode aset, mutasi unit, dan deteksi penyusutan barang kelas.

Dokumen Cloud

Tautkan berkas penting pendukung kurikulum, SK, atau file pendukung lainnya menggunakan link Google Drive.

Tanya & Jawab

Bagaimana cara melakukan login bawaan?

Pilih peran Anda (Wali Kelas / BK / Kepsek / Admin), ketik nama pengguna apa saja, dan gunakan kata sandi utama default kami: sarjanasoft.

Apa yang terjadi jika siswa Alpa 3 hari dalam sebulan?

Sistem EWS secara otomatis mendeteksi siswa tersebut dan memberi label status "Panggilan Pertama (SP1)". Wali kelas dapat memicu dan mencetak dokumen SP1 instan.

Bagaimana status siswa di atas 7 Alpa?

Kasus siswa akan otomatis dikunci dari dashboard Wali Kelas dan langsung dieksalasi ke dashboard Guru BK. Hanya Guru BK yang berwenang memproses mediasi penyelesaian kasus ini.
